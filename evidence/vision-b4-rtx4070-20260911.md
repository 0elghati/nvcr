# Vision B4 RTX 4070 performance delta

Measured on 2026-09-11 with the same RTX 4070, CUDA 12.8, TensorRT 10.9.0,
five exact engine bundles, QP 32 inputs, and Release compiler settings.

- B3 source: `11208d1e23824f69045027af8aa0f17eeae5d6c4`
- B4 source: `10f4975e9e9499232cb57d7ec6994168b7e0bfb2`
- Inputs: `/home/oelghati/datasets/softwarex-inputs.json`
- Engines: `build/engines-b3-rtx4070-catalog`
- Profiles: QCIF, CIF, 360p, 720p, and 1080p
- Protocol: one warm-up, three clean measured runs, with the normal-I/P
  profiling repetition kept separate from throughput
- Release gates: B3 28/28 CTest passed; B4 28/28 CTest passed, including every
  selected engine-contract and I/P round-trip target

The detached B3 worktree was reported dirty only because checkout normalized
line endings in the unrelated RTX 5060 target JSON. The measured B3 source and
binary were built from the recorded commit without source-code changes.

## Pooled equal-work result

| Mode | Metric | B3 | B4 | Delta |
|---|---:|---:|---:|---:|
| Normal I/P | Encode FPS | 114.026037 | 113.691289 | -0.294% |
| Normal I/P | Decode FPS | 118.512719 | 119.942561 | +1.206% |
| All-intra | Encode FPS | 42.389952 | 42.118589 | -0.640% |
| All-intra | Decode FPS | 46.128951 | 46.325372 | +0.426% |

Worst clean-run coefficient of variation improved from 0.370% to 0.199% for
normal-I/P encode, from 0.864% to 0.251% for normal-I/P decode, from 0.241% to
0.159% for all-intra encode, and from 2.208% to 0.366% for all-intra decode.

For every normal-I/P profile, the complete B3 and B4 provider-profile records
are equal. This includes allocation, H2D, D2H, D2D, and synchronization totals
and maxima. The context policy remains `performance`. The graph-cache limit
remains 16 entries per engine, with zero entries, captures, and hits for these
fixtures. Per-frame maxima remain one H2D copy, six D2H copies, and one
synchronization for encode, and five H2D copies, five D2H copies, and five
synchronizations for decode. Payload byte counts are equal in every matched
clean repetition.

The full combined driver exposed an existing recorder limitation for all-intra
profile output: decode frame indices are not contiguous when every frame is an
I-frame. All-intra throughput was therefore rerun without profiling. Normal-I/P
profiling completed for all five profiles. These native regression runs remain
partial publication packages because pinned Python-reference rows were not part
of this B3-to-B4 performance comparison.
