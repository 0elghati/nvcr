B7 makes `RuntimeConfiguration::codec_id` and `provider_id` the explicit
production selectors. `Runtime::create(configuration)` resolves the registered
codec adapter and provider-session factories, then gives the selected
`IProviderSession` to the adapter. The CLI uses this path. Generic runtime code
no longer registers or names DCVC-RT.

The DCVC-RT registry entry now has a real adapter factory. The TensorRT registry
entry now creates the real `TensorRTExecutionSession`; the production
`component_factory` escape hatch and the unused `TensorRTProvider::load` stub
are removed. The older component-level provider API remains only for explicit
artifact clients and deterministic fixtures.
